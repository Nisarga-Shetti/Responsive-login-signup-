# NEXORA – Responsive Login & Signup

A modern, responsive login and signup website built using HTML, CSS, and JavaScript.

## Features

- Responsive login page
- Responsive signup page
- Form validation
- Password minimum length validation (8 characters)
- Confirm password matching
- Duplicate email validation
- Login authentication using browser localStorage
- Clean and modern user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Project Structure

```text
Login-Signup/
├── index.html
├── signup.html
├── style.css
└── script.js
```

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Create an account and test the login page.

## Important Note

This is a frontend practice project. It uses localStorage for demonstration purposes and is not suitable for real user authentication.
